# Anonymous code-release checklist

Before using a code URL in a double-blind submission:

- keep generated datasets and licensed source corpora out of the code repository unless redistribution is permitted;
- remove API keys, local absolute paths, usernames, email addresses, and institutional identifiers;
- verify commit authors/history do not identify the authors if the venue requires anonymous supplementary material;
- keep learner-facing prompts separate from reviewer/gold annotations;
- describe development data as Draft/provisional unless clinical review and adjudication are complete;
- use the conference/workshop-approved anonymous repository or mirror URL rather than a personal GitHub URL.
